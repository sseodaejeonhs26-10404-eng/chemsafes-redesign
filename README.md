# 시약 세이프

설치나 서버 없이 `index.html`을 더블클릭하면 실행됩니다. HTML, CSS, JavaScript만 사용했습니다.

- 시약 5종 검색: 염산, 황산, 수산화나트륨, 에탄올, 아세트산
- 성질·위험·혼합 금지 물질·폐수통 확인·응급 대처 표시
- 2개 이상 선택해 대표 혼합 위험 확인
- 안전 체크 4개를 모두 확인하면 처리 완료 버튼 활성화
- 미등록 시약 안내, 입력 변경 시 기존 체크 초기화

`data.js`의 REAGENTS에 같은 형식의 객체를 추가하면 검색과 선택 목록이 늘어납니다. 별칭은 aliases에, 검토된 조합별 경고는 MIX_RULES에 추가합니다. 규칙이 없는 조합은 안전하다고 표시하지 않습니다.

실제 제품의 농도·첨가물·기존 폐액을 알 수 없으므로 폐수통을 확정하거나 혼합을 허용하지 않습니다. 대표 위험 조합은 완료를 막습니다. 일반 조합도 담당 교사의 개별 처리 지시를 확인해야 합니다. 입력·완료 기록은 저장하지 않습니다. 촬영 인식과 AI 기능은 포함하지 않았습니다.

정보는 CDC/NIOSH Pocket Guide의 각 물질 자료를 참고한 교육용 요약입니다(2026-11-23 확인). 각 검색 결과에 원문 링크를 제공합니다. 제품 SDS 및 학교 과학 교사 검수는 아직 진행하지 않았으므로 수업에 적용하기 전에 해당 제품·농도별 자료와 학교 폐기 지침을 확인해야 합니다.
